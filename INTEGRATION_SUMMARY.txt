================================================================================
                        SYSTEM FLOW
================================================================================

USER JOURNEY:
1. User opens app → MainApp.java loads main.fxml
2. User clicks "Book Now" → MainController opens booking.fxml
3. User enters details → BookingController creates Guest + Invoice
4. User proceeds to payment → PaymentController opens payment.fxml
5. User selects payment method → Creates CashTransaction or CreditCardTransaction
6. Payment processed → transaction.initiateTransaction()
7. If success → BookingDatabase.addBooking() saves to database
8. Confirmation shown → User receives booking ID

ADMIN JOURNEY:
1. User clicks "Sign In" → MainController opens login.fxml
2. User enters credentials → LoginController validates with AccountAddToSQL
3. If valid → DashboardController opens dashboard.fxml
4. Admin clicks "Users" → Displays all accounts in TableView

SEARCH JOURNEY:
1. User clicks "Search Rooms" → MainController opens search.fxml
2. User enters criteria → SearchController calls SearchService
3. SearchService filters rooms → Returns matching List<Room>
4. Results displayed → ListView shows available rooms
